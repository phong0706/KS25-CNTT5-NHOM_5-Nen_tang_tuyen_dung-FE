Tiêu chuẩn kỹ thuật đã đạt

  • ✓ CSS Variables: Đọc trực tiếp --chart-1, --chart-2, --grid, --chart-text.
  • ✓ Tự hủy & vẽ lại: Khi gạt theme (Mặt trăng/Mặt trời), biểu đồ tự destroy và redraw đồng bộ.
  • ✓ 3 Trạng thái chuẩn: Skeleton shimmer, Empty với CTA, Error với nút "Thử lại".
  • ✓ Chiều cao cố định: 280px (nằm trong dải 260-320px), responsive, maintainAspectRatio: false.
  • ✓ Trợ năng (A11y): Thẻ canvas có aria-label + Bảng dữ liệu ẩn (.visually-hidden) cho screen readers.
  • ✓ Định dạng vi-VN: Tooltip tiếng Việt, số hiển thị dấu chấm ngăn cách (1.250.000).
  • ✓ Reduced Motion: Tự động tắt animation vẽ khi hệ điều hành bật chế độ giảm chuyển động.
